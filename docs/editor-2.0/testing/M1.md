# M1 manual test checklist (WP 1.4 + 1.5: editor session, windows, menus, picking, selection overlay)

Setup: Minecraft 26.1.1 with Fabric, Fabric API, Litematica 0.27.14, malilib and the Litematica Array jar. Use a creative singleplayer world with a few `.litematic` files in `schematics/`, loaded as placements, some overlapping. Test once more with the 1.x folders/arrays you had before (they appear under Loose). Anything that fails: note what you did, what you expected and what happened. Run M0.md first.

## Layout and chrome
- [ ] F6: the Scene window (left) and Properties window (right) show, the toolbar is at the top centre, the status bar at the bottom. The game stays visible and clickable between the windows (the central area is transparent).
- [ ] Shift-drag a window title to dock it to an edge; it docks, the middle stays open. Plain drag floats it.
- [ ] Close Scene with its x; Toolbar > Windows (layout icon) > Scene brings it back. "Hide all windows" and Tab hide both, the toolbar and status bar stay. "Reset layout" puts them back at the default spots.
- [ ] Narrow the game window: tool labels disappear first, then the key caps, then the groups after Mirror move into a "..." menu. The toolbar never wraps.
- [ ] Your own player model and its shadow are NOT visible in editor mode (before 2.0 alpha you saw "a shadow of my character"). After F6 again they are back.
- [ ] The status bar hints change: idle, with a selection, while flying (hold RMB), while renaming a row, while dragging a row in the tree.

## Scene window
- [ ] Open projects are listed first (the active one has an ACTIVE badge), Loose is last, then folders, objects, assemblies. Loose placements from Litematica are there as objects.
- [ ] Footer "New project": enter a name, Create. A project appears, becomes active and shows "Empty. Right-click > Add...". "Open project...": lists closed folders in `schematics/Projects`; picking one opens it and its placements appear in the world.
- [ ] Eye icon: hides the object (its placement disappears from the world), again shows it. Ctrl Z undoes it. The row text goes faint while hidden. Hiding a folder hides what is in it.
- [ ] Click selects one row. Shift+click adds/removes. Ctrl+click selects the range from the active row to the clicked one.
- [ ] Double-click a name or F2 renames inline (Enter commits, Esc cancels). Double-click the type icon frames the object in the view.
- [ ] Filter field (also Ctrl F): typing narrows the tree, the matching letters are teal, folders on the way are dim. "Nothing matches" shows a Clear filter button. Chips: Schematics, Assemblies, Areas. "Issues (n)" appears when objects overlap or a placement is missing; it lists them flat, with the project name, front order first.
- [ ] Badges: an object with an Array shows "xN"; with a Boolean the cutter icon; objects that overlap show "P1/P2". Hover a badge for its tooltip. A row with no special state has no badges.
- [ ] Drag a row between two rows: a teal line shows, release reorders. Drag onto a folder: the folder highlights, release moves it in (a collapsed folder opens after 0.6 s). Drag a folder onto itself or onto a linked assembly: the row goes red, the cursor shows "not allowed" and a red reason appears; releasing shows the reason as a toast and nothing changes. Dragging onto another project moves the object there (toast says the file was moved or copied, Undo works).
- [ ] Arrow keys move the selection (the Scene window must be focused), Left/Right collapse/expand, Space toggles visibility, Enter frames.
- [ ] A Loose object whose placement you deleted in Litematica stays in the list greyed out with a "!" badge. Its tooltip says "Placement not found". Right-click > Delete removes it. It is not outlined in the world.
- [ ] Inside a linked assembly, parts show a lock instead of the eye, grey names; selecting one shows the read-only Properties.

## Properties window
- [ ] Nothing selected: the empty hint and the "From Litematica?" card. "Hide this" removes the card for good (stays hidden after restarting the game; delete `config/schemarray/editor-ui.properties` to get it back).
- [ ] Select an object: header with the name field (Enter or leaving the field renames, one undo step), the file path line (click copies it, toast "Path copied"), Transform, Blocks, Front order, Modifiers.
- [ ] Location X/Y/Z: drag a field, type into it (double-click), use - / +. Shift on a stepper moves 16. Holding a stepper keeps moving, and a single Ctrl Z undoes the whole hold. The placement moves in the world after you let go or while dragging.
- [ ] Rotation 0/90/180/270 and the Mirror X toggle change the object in the world; the box stays centred.
- [ ] + Array: a card appears with Count, Relative/Blocks, X/Y/Z offsets and "= ... per copy" text. Changing the count adds/removes copies in the world. The enable switch hides the copies. The "..." menu has Move up/down, Remove (and Realise for arrays). "Realise into N objects" turns copies into objects in a folder.
- [ ] + Boolean: adds a card with Difference/Intersect and an object combo (the cut is not drawn yet; the card says so). Apply is disabled.
- [ ] Select several objects: the batch view ("3 objects"), pivot location rows move the whole group, the rotate buttons turn the group, Mirror X, Front order, Create assembly, Hide, Delete, and a list of the selection (click makes one active).
- [ ] Select a folder, a project, Loose: each shows its own section (counts, Make active, Convert to project...). Convert to project turns the content into a new project (Ctrl Z undoes it).

## Picking and the selection outline
- [ ] Left click an object in the world: it is selected (teal box, name tag above it, row highlighted and scrolled into view in Scene). Click empty space: deselect.
- [ ] Shift+click adds or removes. Alt+click cycles through overlapping objects under the cursor; repeated Alt clicks go through all of them and wrap.
- [ ] Where two objects overlap, a plain click on the shared blocks picks the one in front (lower P number).
- [ ] An object with an array: selecting it also draws fainter boxes around every copy.
- [ ] A hovered object (not selected) gets a thin pale outline.
- [ ] Selected objects behind a wall show a faint teal x-ray box; the solid box is hidden by the wall.
- [ ] A part inside a local assembly: selected from the tree, its box is teal, the assembly's box fainter. Selecting the assembly draws one box around everything.
- [ ] Right click (short, no movement) on an object: it is selected and its menu opens. On empty space: the viewport menu (Add, Select all/none, Frame all, Show hidden, Undo/Redo). Right click on a row in Scene opens that item's menu.
- [ ] Clicks on the Scene/Properties windows or the toolbar never select anything in the world behind them.
- [ ] Double-click an object frames it. F frames the selection (all when nothing is selected).

## Context menus and shortcuts
- [ ] Object menu: Duplicate (copy is selected, offset along X), Linked duplicate, Rename, Transform > Rotate +90/-90, Mirror X, Mirror Z, Modifiers > Add Array/Boolean, Front order, Create assembly, Move to > (projects and folders; the current one is greyed), Hide/Show, Frame, Delete. Delete shows a toast with Undo.
- [ ] Entries for features that are not built yet (Move (G), Box select, Boolean apply, exports, Syncmatica, Top view, assembly .lasm/link, Local view) are greyed with the tooltip "Coming in a later 2.0 alpha".
- [ ] Anything a command refuses (for example Add Array on an object that has one, Make local on a local assembly through a shortcut) shows a toast with the reason instead of doing nothing.
- [ ] Assembly, folder, project, Loose and "part of a linked assembly" menus match DESIGN section 10 (entries that never apply are missing, not greyed).
- [ ] Keys: Ctrl Z, Ctrl Shift Z, Ctrl Y; Shift D, Alt D; H, Alt H; A, Alt A; X and Delete; PgUp/PgDn (Shift for front/back); Ctrl G; M; F2; Tab; Ctrl S saves all; Shift A opens the Add menu at the pointer. None of them fire while typing in a text field.
- [ ] Toolbar Undo/Redo grey out when empty; their tooltips name the step ("Undo Move tunnel (Ctrl Z)").
- [ ] Toolbar Add > Schematic...: pick a file, it is added to the active project (copied into its `files/`) at the camera target and selected.

## Undo and external changes
- [ ] Move a managed placement with Litematica's own hotkeys/GUI (not the editor): the next undo step is "Move ... (outside the editor)"; Ctrl Z puts it back.
- [ ] Restart the game: open projects come back, edits are saved (autosave runs a second after a change, Ctrl S saves at once).
